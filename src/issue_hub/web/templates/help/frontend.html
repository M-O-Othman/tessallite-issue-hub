3. Interactive Web UI Portal

The Issue Hub provides a secure, server-rendered Web UI built using Python FastAPI, Jinja2 template engines, and Bootstrap 5, allowing humans to audit and manage the issue registry.

A. Security and Sessions

Web access requires logging in with admin credentials configured through environment secrets (`ISSUE_HUB_WEB_USERNAME` / `ISSUE_HUB_WEB_PASSWORD_HASH`). Upon authentication, an encrypted, signed session cookie (`issue_hub_session`) is created using Starlette's `SessionMiddleware` to track state securely and statelessly.

B. Portal Pages

1. Summary Dashboard & Filter List:

Displays real-time metric counter cards (All Issues, Open, Closed, Reserved, Retired) and provides multi-variable dropdown controls to filter the ledger list cleanly. Empty selection values are automatically normalized to prevent database query syntax issues.

2. Interactive Creation / Reservation Form:

Allows creating full issues or pre-allocating reserved IDs instantly. The form normalizes input parameters, converts illegal filename characters to dashes, collapses duplicate dashes, and displays a dynamic preview of the generated canonical ID (e.g. tessallite-Bug-9592) based on the project's key template.

3. Detailed Markdown rendering and Audit Timelines:

Displays issue descriptions with styled Markdown rendering (such as headings, lists, tables, and spacing). Includes direct controls to edit metadata fields, append discussion notes with automatic server timezone stamps, or retire duplicate records with explicit duplicate references.

4. Snapshot Deltas Collapsible Logs:

Every issue mutation (creation, reservation, updates, commenting, retirement) writes a record to the issue_history table. The Web portal lists these log entries as an interactive timeline, allowing administrators to expand collapsible panels and inspect raw before/after JSON dictionary representation diffs.
