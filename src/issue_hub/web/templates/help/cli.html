2. Non-Interactive CLI (`issue`)

The issue command-line client is a zero-dependency Python utility designed for seamless execution inside shell scripts and by autonomous AI agents.

A. Configuration Precedence

The CLI evaluates parameters using a strict, predictable precedence chain (Section 17.2):

  1. **Command-Line Option Override** (e.g. --url, --token)
  2. **Environment Variables** (e.g. ISSUE_HUB_URL, ISSUE_HUB_TOKEN, ISSUE_HUB_PROJECT, ISSUE_HUB_REPOSITORY)
  3. **User Configuration File** loaded from OS-specific paths:
    • **Linux/macOS:** ~/.config/tessallite-issue-hub/config.json
    • **Windows:** %APPDATA%\Tessallite\IssueHub\config.json
B. Advisory Git Discovery

If options are absent, the CLI runs background, non-blocking subprocess commands (Section 17.5) to auto-discover parameters from the local repository context:

  • **Worktree Path:** git rev-parse --show-toplevel
  • **Current Branch:** git rev-parse --abbrev-ref HEAD
  • **Repository Name:** Extracted from git config --get remote.origin.url (parsed to isolate the project repo name).
C. Standard Command Examples

Create Complete Issue:

issue create --severity HIGH --title "Dax timeout" --description "Timeout on multi-level filters."

Reserve Number with Zero Details:

issue create --reserve

Search or Find:

Finding by text query executes an all-inclusive wide search across every database column simultaneously (using SQL OR matching). You can search for a sequence number (e.g. 9627), a status (e.g. PARTIAL), a tag, an owner, or a description word:

issue find Bug-9627 --history
issue find "9627"
issue find "hierarchy owner mismatch"

Update Field or Append Description File:

issue update Bug-9627 --set status=MITIGATED --set expected_effort=S
issue update Bug-9627 --append-file closeout_details.md

Retire Duplicate:

issue update Bug-9627 --retire DUPLICATE --duplicate-of Bug-9584 --retire-note "Identical path."
D. Ordering and Paging find

--sort takes a column name and an optional direction, and also accepts field:desc or -field. Lookup-backed columns (status, severity, priority, expected effort) order by their configured rank rather than alphabetically. --limit and --offset page the results, and ordering is deterministic so paging never repeats or skips an issue.

issue find --sort "severity desc" --limit 20
issue find --sort "-updated_at" --limit 20 --offset 40
issue find --branch main --updated-after 01-09-2026

Context options supplied before the subcommand (--project, --repository, --branch, --worktree) apply to the search:

issue --project tessallite find --sort "severity desc"
E. Standard Exit Code Mapping

The CLI writes all JSON response bodies directly to `stdout` and returns exit codes (Section 17.4) indicating the exact transaction result:

  • 0: Success (JSON printed on stdout)
  • 2: Invalid Command/Validation Error
  • 3: Authentication Failure (401)
  • 4: Issue Not Found (404)
  • 5: Service Unavailable / Network Timeout
  • 6: Severe Internal Server Error (500)
